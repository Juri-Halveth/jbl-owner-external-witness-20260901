# JBL QuantumENGINE / QuantumServer: исследование Juri

**Juri (Juri-Halveth) · 27 ноября 2026 года**

[Полный отчёт на немецком](REPORT.md) · [Материалы и указатель источников](evidence/index.json) · [Дополнительная проверка WAN](https://github.com/Juri-Halveth/jbl-wan-proof)

Репозиторий содержит исходный код проверок и сохранившиеся результаты исследования сетевого управления в контексте JBL QuantumENGINE / QuantumServer.

1 сентября 2026 года клиент на GitHub зафиксировал изменение `microphone.gain` **75 → 74 → 75**. Дополнительные запросы чтения подтвердили изменение и восстановление значения. Использовались **временный туннель, созданный владельцем, и предоставленные данные сопряжения**. Отдельная попытка прямого TCP-подключения к порту **57120** завершилась тайм-аутом через **8009 мс**; соединение не установлено, прикладные данные не отправлены.

Опубликованные материалы включают успешную проверку изменения и восстановления, проверку только чтения, неудачный промежуточный запуск и прямую TCP-проверку. Для этого отчёта изучены исторические журналы; повторные сетевые испытания не проводились.

Сами по себе эти результаты не доказывают обход сопряжения, доступ из Интернета при стандартной установке или превышение предусмотренных прав сопряжённого клиента. Точная версия исследованного QuantumENGINE / QuantumServer в сохранившихся записях не указана. Дополнительное чтение означает ещё один запрос того же клиента, а не физическое измерение микрофона.

В прочитанных 27 ноября официальных примечаниях JBL указана **QuantumENGINE 2.9.4 от 3 ноября 2026 года**. В проверенных примечаниях и списке HARMAN у CERT@VDE не найдено подтверждение исправления, однозначно относящееся к этому сообщению. Текущая версия практически не проверялась. Полный отчёт отдельно указывает этот статус и происхождение сведений о переписке и вознаграждении.

В `evidence/` сохранены извлечённые исторические результаты со ссылками на исходные запуски. Редактирование отпечатка данных сопряжения явно отмечено.
